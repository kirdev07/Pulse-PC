# Pulse PC: установка и запуск (только Python, без exe)

Никаких `.exe` и сборки не нужно: программа работает как обычные Python‑скрипты.

## Что нужно один раз
Установленный **Python 3.10 или новее (64‑bit)**: https://www.python.org/downloads/
При установке поставьте галочку **Add python.exe to PATH**.

## Быстрый старт (2 шага)
1. Дважды щёлкните **`install.bat`**. Он создаст окружение `.venv`, поставит пакеты и положит ярлык **Pulse PC** на рабочий стол.
2. Запускайте через ярлык (или двойным щелчком по **`PulsePC.pyw`**).

Первый запуск без установщика тоже работает: откройте `PulsePC.pyw`, окно покажет прогресс и само запустит программу.

## Первая настройка программы
Вкладка **Настройки** → токен бота и свой Telegram ID → «Сохранить настройки» → «Запустить».

## Телефон (Android)
1. Установите APK приложения на телефон (в установочной папке: `android/PulsePC-Android.apk`, если он есть).
2. Откройте приложение: оно само находит ПК в той же Wi‑Fi сети. При первом подключении на ПК появится окно
   «Разрешить телефон?». Подключённые телефоны видно и можно отозвать на вкладке **Телефон**.

## Часы (Galaxy Watch / Wear OS)
Приложение для часов лежит в `android/PulsePC-Watch.apk` (исходники: отдельный проект `Pulse_Pc_Watch`).
Работает само по Wi‑Fi, телефон не нужен.

**Установка на часы** (один раз):
1. На часах: Настройки → О часах → Сведения о ПО → 5 раз нажать «Версия ПО» → включить «Отладка по Wi‑Fi».
2. На ПК (папка `platform-tools` из Android SDK, часы и ПК в одной сети):
   `adb pair IP:ПОРТ` (код с часов), затем `adb connect IP:ПОРТ`, затем `adb -s IP:ПОРТ install -r PulsePC-Watch.apk`.
3. Откройте Pulse PC на часах, нажмите на свой ПК и подтвердите запрос на ПК.

**Что есть на часах:** плеер ПК (⏮ ⏯ ⏭, громкость ползунком, выбор источника: локальная музыка Pulse PC, стриминг или
браузер, кнопка «Открыть на ПК»), программы и сценарии, блокировка, сон, таймер выключения, состояние ПК.
В фоне служба показывает музыку ПК в системном плеере часов; колесо и кнопки громкости часов меняют громкость ПК.
Экономия заряда: пока экран выключен, часы ничего не опрашивают и отпускают Wi‑Fi.
Для точной громкости (ползунок 0–100) на ПК нужен пакет `pycaw` (ставится установщиком из `requirements-optional.txt`).

## Автозапуск вместе с Windows
В программе: **Настройки** → «Запускать Pulse PC вместе с Windows».
Из командной строки: `python launcher.py --autostart on` (выключить: `off`).

## Если что‑то не работает
| Симптом | Что сделать |
| --- | --- |
| «Python не найден» | Установите Python (см. выше), потом снова `install.bat` |
| Ошибка при установке пакетов | Смотрите `install.log`; проверьте интернет и запустите `install.bat` ещё раз |
| Программа не открывается | `python launcher.py --check` покажет, готово ли окружение |
| Хочу переустановить пакеты | Удалите папку `.venv` и запустите `install.bat` |

## Файлы
- `PulsePC.pyw`: запуск двойным щелчком (без чёрного окна).
- `launcher.py`: подготовка окружения, ярлык, автозапуск (`--install`, `--check`, `--autostart on|off`).
- `requirements.txt`: обязательные пакеты. `requirements-optional.txt`: необязательные (показ «что играет» из других программ).
- `gui.py`, `bot_runtime.py`, `modules/`…: сама программа. Настройки и токен бота хранятся в папке `config/` и в репозиторий не попадают.
