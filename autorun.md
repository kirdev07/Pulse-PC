# Настройка запуска и автозагрузки Pulse PC 🖥️⚙️

Поскольку проект переведен на автономное графическое приложение с иконкой на панели задач, настройки и автозапуск стали значительно проще.

---

## 🚀 Основной запуск приложения
Просто запустите файл **`Pulse PC.exe`** в корневой папке вашего проекта.
* **При первом запуске**: Перейдите на вкладку **«Настройки»**, вставьте ваш токен бота и Telegram ID, после чего нажмите **«Сохранить настройки»**.
* **Управление ботом**: Запуск и остановка бота выполняются одной кнопкой прямо в интерфейсе. Консоль логов в реальном времени покажет состояние подключения.
* **Сворачивание**: При нажатии на крестик (закрытие окна) приложение автоматически сворачивается в системный трей (у часов) и продолжает работать на заднем плане.
* **Выход**: Чтобы полностью завершить работу, кликните правой кнопкой мыши по иконке в трее и нажмите **«Выход»**.

## ⚙️ Автозапуск при старте Windows
Чтобы бот автоматически запускался и работал на фоне сразу после включения компьютера (в свернутом виде без открытия лишних окон), выберите один из двух способов:

### Способ 1. Через папку Автозагрузки Windows (Рекомендуемый / Простой)
1. Нажмите сочетание клавиш **`Win + R`** на клавиатуре.
2. Введите команду **`shell:startup`** и нажмите **Enter**. Откроется системная папка автозагрузки.
3. Нажмите правой кнопкой мыши на файл **`Pulse PC.exe`** в корневой папке бота и выберите **«Создать ярлык»**.
4. Переместите созданный ярлык в открывшуюся папку `shell:startup`.
5. Кликните правой кнопкой мыши по ярлыку в папке автозагрузки -> **Свойства**.
6. Во вкладке **«Ярлык»** найдите поле **«Объект»** и добавьте в самый конец через пробел параметр `--minimized` (или `-m`).
   * Пример строки в поле Объект: `"D:\Android_App\Telegram PC Bot\Pulse PC.exe" --minimized`
7. Нажмите **ОК**. Теперь при включении ПК приложение будет запускаться скрытно, сразу сворачиваясь в трей, и автоматически запускать бота!

---

### Способ 2. Через Планировщик задач (Для скрытого запуска с правами админа)
Этот способ нужен, если вы хотите, чтобы команды управления ПК (запуск/закрытие программ с правами администратора) работали без ограничений Windows (UAC).

1. Нажмите сочетание клавиш **`Win + R`**, введите **`taskschd.msc`** и нажмите **Enter** (откроется Планировщик задач).
2. В правом столбце действий нажмите **«Создать простую задачу...»**.
3. Введите имя задачи (например, `Pulse PC`) и нажмите **«Далее»**.
4. Выберите триггер **«При входе в Windows»** и нажмите **«Далее»**.
5. Выберите действие **«Запуск программы»** -> **«Далее»**.
6. В поле **«Программа или сценарий»** нажмите **«Обзор...»** и выберите ваш файл:
   `D:\Android_App\Telegram PC Bot\Pulse PC.exe`
7. **⚠️ ВАЖНО (Рабочая папка и аргументы):**
   * В поле **«Добавить аргументы (необязательно)»** вставьте: `--minimized`
   * В поле **«Рабочая папка (необязательно)»** обязательно вставьте полный путь к папке бота:
     `D:\Android_App\Telegram PC Bot\`
8. Нажмите **«Далее»**, отметьте галочку **«Открыть окно свойств для этой задачи после нажатия кнопки Готово»** в самом низу, и нажмите **«Готово»**.
9. В открывшемся окне свойств на вкладке **«Общие»**:
   * Поставьте галочку **«Выполнять с наивысшими правами»** (это даст боту права администратора).
   * Выберите **«Выполнять только при вошедшем в систему пользователе»** (чтобы иконка в трее была видна на экране и вы могли ее использовать) или **«Выполнять независимо от того, вошел ли пользователь в систему»** (для полной скрытности без отображения иконки).
10. Нажмите **«ОК»** для сохранения.

## 📌 Закрепление на Панели задач
Вы можете закрепить запущенное приложение на панели задач Windows, кликнув правой кнопкой мыши по его иконке на панели задач и выбрав **«Закрепить на панели задач»**. Красивый значок темно-синего монитора со светящимися глазами робота будет всегда под рукой для ручного запуска!
