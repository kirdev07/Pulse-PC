## О проекте

**Pulse-PC** — настольная панель управления компьютером на **Python**, которая объединяет Telegram-бота, мониторинг системы, файловые операции, управление программами, мультимедиа и локальный API для мобильных устройств.

Проект ориентирован на **Windows**. Приложение запускается из исходников через Python и **не требует сборки в .exe**. Графический интерфейс построен на **PySide6 (Qt)** и оформлен в монохромном стиле **Pulse-PC Fusion**.

> **Важно:** Pulse-PC предоставляет удалённые действия с компьютером. Настраивайте доступ только для собственного ПК, храните токен Telegram-бота в секрете и подключайте мобильные устройства только в доверенной локальной сети.

## Возможности

### Рабочий стол Pulse-PC

- **Главная панель:** состояние Telegram-бота, запуск и остановка, сведения о компьютере, обновление показателей нагрузки.
- **Программы:** создание и редактирование списка приложений, запуск и завершение настроенных программ.
- **Консоль:** просмотр событий и сообщений приложения.
- **Настройки:** Telegram-токен и ID администратора, параметры работы, автозапуск вместе с Windows.
- **Телефон:** управление локальным сервером, подключёнными устройствами и разрешением новых сопряжений.
- **Плеер:** управление воспроизведением и собственная музыкальная библиотека Pulse-PC.
- **Файловые передачи:** выбор файлов для отправки администратору в Telegram, отображение прогресса и отмена очереди.

### Управление через Telegram

После настройки личного бота доступны:

| Раздел | Что можно делать |
| --- | --- |
| **Система** | Блокировать ПК, переводить в сон, выключать и перезагружать с подтверждением |
| **Таймер** | Назначать и отменять отложенное выключение или перезагрузку |
| **Программы** | Запускать настроенные приложения и завершать процессы |
| **Сценарии** | Запускать заранее сохранённые наборы программ |
| **Окна** | Просматривать открытые окна, сворачивать, разворачивать и выводить на передний план |
| **Файлы** | Просматривать папки и диски, отправлять файлы в Telegram и принимать вложения на ПК |
| **История файлов** | Смотреть последние передачи и повторять доступные неудачные отправки |
| **Экран** | Получать скриншоты с выбором монитора |
| **Мультимедиа** | Переключать треки, ставить на паузу, изменять громкость и отключать звук |
| **Информация** | Запрашивать состояние и сведения о компьютере |
| **Поиск и ссылки** | Выполнять поиск и открывать ссылки на компьютере |
| **Избранное** | Размещать часто используемые действия и программы в верхней части меню |
| **Уведомления** | Получать настроенные оповещения о CPU, свободном месте и завершении отслеживаемых процессов |

**Некоторые особенности Telegram-функций:**

- Передача файлов **с ПК в Telegram — до 50 МБ на файл**, приём вложений из Telegram **до 20 МБ** в пределах логики приложения.
- История хранит **последние 100 попыток передачи**.
- В избранное можно добавить **до 6** программ или действий.
- Поддерживается **до 20 сценариев**, каждый — до **15 программ**.
- Для таймера питания требуется подтверждение; максимальная задержка — **1440 минут**.
- При блокировке Windows команды управления ограничиваются. Подробные исключения и поведение описаны в [BOT_GUIDE.md](BOT_GUIDE.md).

### Pulse Mobile — управление ПК с Android

**[Pulse Mobile Client](https://github.com/kirdev07/Pulse-Mobile-Client)** — официальный мобильный клиент экосистемы Pulse от **KirDev Studio**. Это отдельное Android-приложение на **Kotlin**, которое подключается к Pulse-PC на Windows через локальную сеть. Исходники Android-клиента находятся в собственном репозитории; они **не входят** в Windows-архив.

| Компонент | Pulse-PC для Windows | Pulse Mobile для Android |
| --- | --- | --- |
| **Роль** | Основная программа, интерфейс Fusion, Telegram-бот и локальный сервер | Мобильная панель управления подключённым компьютером |
| **Платформа** | Windows, Python 3.10+, PySide6 | Android 11+, Kotlin, Android Views / Material |
| **Подключение** | Запускает локальный HTTP API и подтверждает сопряжение | Находит ПК по Wi-Fi, запрашивает сопряжение и сохраняет подключение |
| **Распространение** | [ZIP с исходниками](https://github.com/kirdev07/Pulse-PC/releases) без .exe | [Отдельные исходники и возможные APK-релизы](https://github.com/kirdev07/Pulse-Mobile-Client/releases) |

**Что доступно с телефона в текущем исходном коде клиента:**

- **Главная:** состояние ПК, информация о соединении и быстрые действия.
- **Питание и Windows:** блокировка, сон, выключение и перезагрузка с подтверждением, таймер питания, закрытие активного окна.
- **Программы:** запуск и завершение программ, настроенных в Pulse-PC.
- **Сценарии:** запуск сохранённых на компьютере наборов программ.
- **Окна:** просмотр, вывод на передний план, сворачивание и закрытие.
- **Файлы:** просмотр дисков и каталогов, скачивание с ПК в `Загрузки/PulsePC`, отправка файлов с Android на ПК и история передач.
- **Музыка:** воспроизведение, пауза, следующий/предыдущий трек, перемотка, громкость, выбор доступных источников, библиотека и обложки.
- **Экран:** получение скриншотов и выбор монитора.
- **Поиск и ссылки:** открытие сайтов и поисковых запросов на ПК.
- **Фоновое управление музыкой:** медиакнопки и сведения о треке в уведомлениях Android и на экране блокировки через `PulseService`.
- **Несколько компьютеров:** список ранее сопряжённых ПК и переключение между ними.

**Как подключить Android:**

1. Установите и запустите Pulse-PC на компьютере.
2. Во вкладке **«Телефон»** включите локальный сервер и разрешите новые подключения.
3. Подключите ПК и Android к одной **доверенной локальной сети Wi-Fi**.
4. В Pulse Mobile запустите поиск ПК и выберите свой компьютер.
5. **Подтвердите сопряжение на Windows-компьютере** — телефон получит индивидуальный токен.
6. Откройте панель управления. Для отзыва доступа удалите устройство в Pulse-PC; простое удаление сохранённого ПК на телефоне не отзывает серверный токен.

Для обнаружения используется UDP (порт **8766**), для запросов — локальный HTTP API (обычно порт **8765**). Работу могут ограничивать брандмауэр Windows, изоляция клиентов Wi-Fi и версия сервера.

**Важно:** Android-клиент сейчас использует **HTTP без TLS** и хранит выданные токены в обычных Android SharedPreferences. Пользуйтесь им только в доверенной сети, не пробрасывайте серверный порт в интернет. Подробнее: [README мобильного приложения](https://github.com/kirdev07/Pulse-Mobile-Client/blob/main/README.md), [политика конфиденциальности](https://github.com/kirdev07/Pulse-Mobile-Client/blob/main/PRIVACY_POLICY.md) и [безопасность](https://github.com/kirdev07/Pulse-Mobile-Client/blob/main/SECURITY.md).

**Приложение для часов в текущую экосистему не входит.** Готовый APK доступен только при отдельной публикации в релизах Pulse-Mobile-Client.

### Безопасность и ограничения

- Для защищённых маршрутов локального API нужен индивидуальный токен сопряжённого устройства.
- Токены устройств хранятся локально в виде SHA-256-хешей; отдельный доступ можно отозвать.
- Новое сопряжение требует подтверждения владельцем на ПК; запросы ограничиваются по частоте.
- Публичный HTTP-ответ `/api/ping` не раскрывает имя компьютера.
- Неожиданные ошибки API не возвращают клиенту внутренний текст исключения.
- **Локальный HTTP API не использует TLS:** трафик в LAN не шифруется. Не открывайте порт в интернет, не настраивайте проброс портов и не используйте API в недоверенном Wi-Fi.
- Обнаружение по UDP и подтверждённое сопряжение могут передавать имя компьютера.
- Доступность действий зависит от состояния Windows, прав пользователя и настроек приложения.

Подробнее: [Политика конфиденциальности](PRIVACY_POLICY.md) · [Обзор безопасности](SECURITY_REVIEW_1_0.md).

## Скачать и установить Pulse-PC на Windows

### Готовый архив из GitHub Releases

1. Откройте **[GitHub Releases](https://github.com/kirdev07/Pulse-PC/releases)**.
2. Выберите выпуск **v1.0.0** и скачайте архив **`Pulse-PC-1.0.0-Windows-Python.zip`**, если он опубликован в Assets.
3. Распакуйте архив в отдельную папку.
4. Установите **Python 3.10+ (64-bit)** с включённым **Add Python to PATH**.
5. Запустите **`install.bat`**. Скрипт подготовит виртуальное окружение и установит зависимости.
6. Откройте **Pulse-PC** через созданный ярлык или файл **`PulsePC.pyw`**.
7. В настройках укажите токен своего Telegram-бота и собственный Telegram ID, сохраните настройки и запустите бота.

**Никакого .exe или PyInstaller не требуется.** Для первой установки необходим интернет, чтобы скачать Python-зависимости.

### Запуск из Git-репозитория

```powershell
git clone https://github.com/kirdev07/Pulse-PC.git
cd Pulse-PC
python launcher.py --install
python launcher.py
```

Проверка окружения:

```powershell
python launcher.py --check
```

Автозапуск Windows настраивается из приложения либо командой `python launcher.py --autostart on`.

Полная инструкция и решение типичных проблем: **[УСТАНОВКА.md](УСТАНОВКА.md)**.

## Настройка Telegram-бота

1. Создайте бота через **@BotFather** в Telegram и получите токен.
2. Узнайте свой числовой Telegram ID.
3. В Pulse-PC откройте **Настройки**, укажите токен и ID администратора.
4. Сохраните параметры, запустите бота и отправьте ему **`/start`** в личном чате.
5. Используйте меню кнопок или команды `/help`, `/status`, `/files`, `/scenarios`, `/windows`, `/history`.

**Не публикуйте токен бота и содержимое локального файла `config/.env`.** Все команды и ограничения подробно описаны в **[BOT_GUIDE.md](BOT_GUIDE.md)**.

## Частые вопросы

**Нужен ли .exe?** Нет. Pulse-PC работает непосредственно на Python.

**Можно ли запустить на Linux или macOS?** Выпуск 1.0 ориентирован на Windows и использует Windows-специфичные библиотеки.

**Нужен ли Telegram для управления через Android?** Android-клиент работает через локальный API, но доступность сервера зависит от запуска соответствующих компонентов Pulse-PC.

**Можно ли подключаться из интернета напрямую?** Не рекомендуется. LAN API использует HTTP без TLS и рассчитан на доверенную локальную сеть.

**Почему не подключается телефон?** Проверьте, что ПК и телефон находятся в одной сети, сервер включён во вкладке «Телефон», запрос сопряжения подтверждён, а Windows Firewall не блокирует подключение.

**Где посмотреть команды бота?** В [BOT_GUIDE.md](BOT_GUIDE.md).
