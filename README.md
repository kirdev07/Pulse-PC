# Pulse PC

Управление компьютером с телефона: из Telegram и из Android‑приложения по локальной сети.
Работает как обычная программа на Python, **без exe**.

## Возможности
- **Главная:** нагрузка ПК, блокировка, сон, выключение и перезагрузка с таймером, закрытие активного окна.
- **Программы, сценарии, окна:** запуск и закрытие, запуск наборов программ, управление окнами.
- **Файлы:** обзор дисков и папок, скачивание на телефон, отправка файлов на ПК, история передач.
- **Плеер:** что играет на ПК (Яндекс Музыка, браузер, Spotify…) с обложкой, перемоткой, кнопками и громкостью;
  свой плеер Pulse PC с библиотекой музыки, треки можно запускать с телефона.
- **Экран:** скриншоты ПК с выбором монитора, открытие ссылок и поиск на ПК.
- **Уведомления на телефон:** оповещения Pulse PC, статус подключения, плеер в шторке и на экране блокировки.
- **Безопасность:** новый телефон подключается только после подтверждения на ПК; доступ можно отозвать.

## Часы (Wear OS)
Отдельное приложение для Galaxy Watch: плеер ПК с выбором источника (локально / стриминг / браузер), программы, сценарии, быстрые действия, работа в фоне и экономия заряда. Подробнее в [УСТАНОВКА.md](УСТАНОВКА.md).

## Установка (Windows)
1. Поставьте Python 3.10+ (64‑bit) с галочкой «Add python.exe to PATH».
2. Запустите `install.bat`: он создаст окружение, поставит пакеты и сделает ярлык.
3. Запускайте ярлык «Pulse PC» или `PulsePC.pyw`.

Подробнее: [УСТАНОВКА.md](УСТАНОВКА.md). Инструкция по боту: [BOT_GUIDE.md](BOT_GUIDE.md).

## Android‑приложение
Приложение для телефона распространяется отдельно (файл APK, исходники в этот репозиторий не входят). Оно находит ПК в Wi‑Fi само, при первом подключении подтвердите запрос на ПК.

## Структура
| Путь | Что это |
| --- | --- |
| `gui.py`, `bot_runtime.py`, `player_controller.py` | окно программы, Telegram‑бот, плеер |
| `modules/` | обработчики бота, API для телефона (`local_api.py`), доступ телефонов (`mobile_access.py`) |
| `launcher.py`, `PulsePC.pyw`, `install.bat` | установка и запуск |
| `tests/` | тесты (`python -m unittest discover -s tests`) |

Настройки и токен бота хранятся в `config/` и не попадают в репозиторий.
